A framework for an AI competition run by [Abakus GameDev](https://www.facebook.com/groups/1498086230434830/), a game development student organization. The game features top-down tank combat, and the goal is to be the last one standing.

Commands are issued over sockets, and the game is written in Java with [libGDX](https://libgdx.com/).
