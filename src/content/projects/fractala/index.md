I am co-developing *Fractala Sandbox*, a 2D physics sandbox game that has been under active development since 2019.

The game is written in a custom C++ engine and makes heavy use of compute shaders. It implements a comprehensive position-based dynamics particle simulation that can run hundreds of thousands of particles on a wide range of devices.

Building the engine from scratch has taught me a lot about optimizing games and keeping communication between the GPU and CPU efficient.
