A simple IDE for the [AngelScript](https://www.angelcode.com/angelscript/) scripting language, made with [Qt 4](https://www.qt.io/) and [QScintilla](https://riverbankcomputing.com/software/qscintilla/) for syntax highlighting.

It supports opening and creating projects, cascading and tab-based editing, and simple debugging with breakpoints and code stepping.
